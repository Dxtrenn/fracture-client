FAQ

Is Fracture Client free?

Yes, completely free.

Do I need to own Minecraft?

Yes. You log in with the Microsoft account that owns Minecraft Java Edition, the same as the official launcher.

Is it safe? Why does Windows warn me?

The full source code is public on GitHub. Windows warns about any app that isn't signed with a paid certificate; click More info â†’ Run anyway.

Will it mess up my normal .minecraft folder?

No. Fracture keeps its own game folder, so your other launchers stay exactly as they are.

Which versions does it support?

Every Minecraft Java release, Vanilla or Fabric, from 1.8.9 to the newest version.

Does it work on Mac or Linux?

Not yet. Fracture Client is Windows only for now.
